# Reproducibility Outputs

This directory contains the tables and figures generated by the canonical analysis pipeline used for the case study.

The outputs are intentionally versioned with the code so that the numerical evidence cited in the report can be audited without relying on an external workbook.

The raw OSMI CSV is not included because it is the supplied source dataset and remains excluded under `data/*.csv`.

Run `python run_all.py` after placing the source CSV in `data/` to regenerate these artefacts.
